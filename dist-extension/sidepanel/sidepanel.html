Backend Setup Required
To enable full AI chat functionality, please start the Cline backend services in your terminal:
  1. 1. Start Hostbridge Service
    cd dist-standalone/extension && ./cli/bin/cline-host --port 26041 --verbose
    Handles file system and terminal operations
  2. 2. Start Cline Core Service
    cd dist-standalone && node cline-core.js --port 8080 --host-bridge-port 26041
    Provides AI chat and gRPC services
  3. 3. Verify Connection
    curl http://localhost:8001/health
    Should return {"status":"ok"} when services are running

Available Without Backend:

  • ✅ Webpage interaction (reading, clicking, form filling)
  • ✅ Browser-based file operations
  • ✅ Basic text editing and note-taking
  • ❌ AI chat (requires backend)
  • ❌ Advanced file operations
  • ❌ Terminal access
